# 🏸 川崎礼盒 · 图册

纯静态图片展示页。**上传图片即自动更新，不用改代码。**

---

## 怎么更新

### 新增图片

1. 进入仓库，点开 `images` 文件夹
2. 点右上角 `Add file` → `Upload files`
3. 把图片拖进去
4. 拉到页面底部点 `Commit changes`

刷新页面就能看到。没变化就按 `Ctrl + F5` 强制刷新（手机上把页面完全关掉再打开）。

### 删除图片

在 `images` 文件夹里点开那张图 → 右上角垃圾桶图标 → `Commit changes`。页面同步移除。

### 批量上传（图片多时用）

```bash
git clone https://github.com/你的用户名/你的仓库名.git
cd 你的仓库名
# 把图片复制到 images/ 文件夹
git add images/
git commit -m "新增：极光7星座限定"
git push
```

### 更新后没反应？

按顺序排查：

1. **等 5 分钟**。页面有 5 分钟缓存，强制刷新也绕不过
2. **CDN 延迟**。页面走 jsDelivr 加速，刚提交的文件可能要几分钟才同步到
3. 确认图片确实在 `images/` 文件夹里，不是传到了根目录
4. 确认文件名后缀是小写，`.PNG` 不识别
5. 按 F12 打开控制台，看有没有红色报错

## 怎么命名

**文件名决定三件事**：卡片显示的文字、归到哪个系列、图片本身。

### 基本规则

- 文件名（去掉扩展名）会**原样显示**在卡片下方，所以中文名直接写就行
- 支持的格式：`.png` `.jpg` `.jpeg` `.webp` `.gif` `.avif`
- **后缀必须小写**，`.PNG`、`.JPG` 不认
- 建议单张压到 300KB 以内，手机上打开快很多

### 分类规则

程序按下面的顺序匹配文件名，**命中即停**。文件名里带对应关键词，就会自动归到那个系列。

| 顺序 | 系列 | 关键词 |
|---|---|---|
| 1 | ＆ 12星座系列 | 星座、白羊、金牛、双子、巨蟹、狮子、处女、天秤、天蝎、射手、摩羯、水瓶、双鱼 |
| 2 | ⚡ 极光系列 | 极光 |
| 3 | 🐦 青鸟系列 | 青鸟 |
| 4 | 🔩 螺纹钢系列 | 螺纹钢 |
| 5 | 🎋 国风系列 | 定风波、赤壁赋、金榜题名、竹影、凤栖 |
| 6 | 🎨 艺术·联名·限定 | 莫奈、梵高、达芬奇、星月夜、麦田、睡莲、鸢尾、向日葵、岩间圣母、丝柏、联名 |
| — | 🎁 其他主题礼盒 | 以上都不含（兜底） |

**注意顺序**：`川崎礼盒-极光7狮子座礼盒.png` 同时含"极光"和"狮子座"，因为星座排在第 1 位，会归到 **12星座系列**，不是极光系列。

### 命名示例

```
✅ 川崎礼盒-极光7礼盒03.png            → ⚡ 极光系列
✅ 川崎礼盒-极光7PRO礼盒-蓝01.png        → ⚡ 极光系列
✅ 川崎礼盒-青鸟礼盒08-凤凰游.png        → 🐦 青鸟系列
✅ 川崎礼盒-螺纹钢礼盒01-银色版.jpg      → 🔩 螺纹钢系列
✅ 川崎礼盒-定风波礼盒01-竹林版.png      → 🎋 国风系列
✅ 川崎礼盒-莫奈-睡莲01.png              → 🎨 艺术·联名·限定
✅ 川崎礼盒-极光7狮子座礼盒.png          → ＆ 12星座系列
✅ 川崎礼盒-独角兽礼盒01.png             → 🎁 其他主题礼盒（不含关键词，兜底）
```

### 归错系列了怎么办

三种改法，从简单到彻底：

**① 改文件名**（最推荐）
把图片重命名，让关键词对上。比如 `梧桐凤栖.png` 想放"其他"却因为含"凤栖"进了国风，改成 `梧桐礼盒.png` 就行。在 GitHub 上点开图片 → 铅笔图标 → 改名 → Commit。

**② 用 OVERRIDE 手动指定**
打开 `index.html`，找到这段：

```js
const OVERRIDE = {
    // '川崎礼盒-梧桐-凤栖礼盒01': 'other',
};
```

加一行，键是**去掉扩展名的完整文件名**，值是系列代号：

```js
const OVERRIDE = {
    '川崎礼盒-梧桐-凤栖礼盒01': 'other',
    '川崎礼盒-极光7情人节05': 'aurora',
};
```

系列代号对照：

| 代号 | 系列 |
|---|---|
| `xingzuo` | ＆ 12星座系列 |
| `aurora` | ⚡ 极光系列 |
| `bluebird` | 🐦 青鸟系列 |
| `rebar` | 🔩 螺纹钢系列 |
| `dingfengbo` | 🎋 国风系列 |
| `art` | 🎨 艺术·联名·限定 |
| `other` | 🎁 其他主题礼盒 |

**③ 加新系列**
在 `index.html` 的 `SERIES` 数组里加一项：

```js
{ id: 'newseries', title: '🌟 新系列' },
```

再到 `RULES` 里加匹配关键词：

```js
{ id: 'newseries', re: /关键词1|关键词2/ },
```

位置放在哪一行，就代表优先级排在哪。

## 页面表现

- **懒加载**：图片滚到视口附近才开始下载，首屏快，省流量
- **移动端**：手机自动切两列布局，字号、间距都缩小，适配刘海屏和底部横条
- **CDN 加速**：图片走 jsDelivr，国内访问比 GitHub 原地址快很多；CDN 失败自动回退
- **容错**：图片缺失显示"🖼️ 图片缺失"占位，不会撑破版式
