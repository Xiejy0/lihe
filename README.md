# 🏸 川崎礼盒 · 图册

纯静态图片展示页。**上传图片即自动更新，不用改代码。**

---

## 怎么更新

### 新增图片

1. 进入仓库，点开 `images` 文件夹
2. 点右上角 `Add file` → `Upload files`
3. 把图片拖进去
4. 拉到页面底部点 `Commit changes`

刷新页面就能看到。没变化就按 `Ctrl + F5` 强制刷新。

### 删除图片

在 `images` 文件夹里点开那张图 → 右上角垃圾桶图标 → `Commit changes`。页面同步移除。

### 重命名图片

点开图片 → 铅笔图标 → 改文件名 → `Commit changes`。

### 批量上传

```bash
git clone https://github.com/xiejy0/lihe.git
cd lihe
# 把图片复制到 images/ 文件夹
git add images/
git commit -m "新增：极光7星座限定"
git push
```

## 怎么命名

**文件名决定卡片显示的文字，以及归到哪个系列。**

- 文件名（去掉扩展名）会**原样显示**在卡片下方，中文名直接写
- 支持的格式：`.png` `.jpg` `.jpeg` `.webp` `.gif` `.avif`
- **后缀必须小写**，`.PNG`、`.JPG` 不认
- 建议单张压到 300KB 以内
- **不要用全角符号**，`－`（全角）和 `-`（半角）长得一样但会导致图片加载失败

### 归错系列了怎么办

**改文件名**最快。让关键词对上就行。

不想改文件名，就编辑 `app.js` 里的 `OVERRIDE`：

```js
const OVERRIDE = {
    '川崎礼盒-梧桐-凤栖礼盒01': 'other',
};
```

键是去掉扩展名的完整文件名，值是系列代号：

`xingzuo` `aurora7` `aurora7pro` `aurora50` `auroraOther` `bluebird` `rebar` `dingfengbo` `art` `other`

### 调整显示顺序

页面从上到下的顺序由 `app.js` 里的 `SERIES` 数组决定，调换行顺序即可。

**注意**：`SERIES` 管显示顺序，`RULES` 管分类优先级，两者独立。所以极光7 可以显示在极光7 Pro 前面，但 `RULES` 里 Pro 依然要排在前面。

## 错误提示

### 页面显示「图片缺失」

说明文件被找到了，但**浏览器下载失败**。不是文件不存在。

按 `F12` → `Network` → `Ctrl + R` → 点 **Img** 筛选，找红色请求，看 Request URL。把 URL 复制到新标签页打开：

- **打开也是 404** → 文件名有问题（多半是全角符号），重命名成纯半角
- **能打开** → CDN 延迟，等几分钟
- **显示 GitHub 404 页面** → 路径不对

临时验证是不是 CDN 问题：把 `app.js` 里 `USE_CDN` 改成 `false`，强刷，图出来了就是 CDN 延迟。

控制台也会打印失败详情：

```
[图片加载失败] {名称: '...', CDN地址: '...', 回退地址: '...'}
```

### 页面显示「加载失败」

- 仓库必须是 **Public**
- `app.js` 里的 `OWNER` / `REPO` / `BRANCH` 填对（`xiejy0` / `lihe` / `main`）
- `images` 文件夹必须真实存在，里面至少有一张图
- 用 `file://` 直接打开本地文件无法访问 API，必须部署到 GitHub Pages

### 更新后页面没变化

1. **等 5 分钟**。页面有 5 分钟缓存
2. **CDN 延迟**。jsDelivr 对刚提交的文件需要几分钟同步
3. 强制刷新 `Ctrl + F5`，手机把标签页完全关掉重开
4. 改过分类规则的话，F12 → Console 执行 `localStorage.clear(); location.reload();` 清缓存
